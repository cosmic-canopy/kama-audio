# @kama/audio

An audio library for [kama](https://kama-lang.org), on the browser's Web Audio and the same API natively: playback,
mixing, effects and spatial sound. It names no engine, so a tool, an editor, a product or a game can use it.

**Status: seeded, not built.** `src/audio.kama` is `kama seed`'s placeholder, and a design pass comes first.
